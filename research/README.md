# Preserved research workspace

This directory keeps the original experiment scripts and their relative paths. Start with the release [README](../README.md), [source guide](../docs/SOURCE_GUIDE.md) and [protocol guide](../docs/PROTOCOLS.md).

The former project README is retained as [README.historical.md](README.historical.md). It describes an earlier class-specific diagnostic protocol and contains outdated directory descriptions; it is not the current execution guide.

These scripts require the original image/model/cache layout, and some earlier paths or imports need adaptation. The tested, portable commands are in `../scripts/`. The inherited `requirements.txt` records a historical environment; use the requirement groups at the release root for the supported entry points.

No original workspace file was moved or overwritten. Copies with local-path adjustments are recorded in `../docs/source_manifest.json`.
