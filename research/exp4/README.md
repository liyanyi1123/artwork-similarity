# Exp4 — Datasets5 fixed CLIP + ViT threshold

This experiment evaluates all Datasets5 (ArtBench-10) pairs under one fixed decision rule:

`CLIP cosine similarity > 0.8 AND ViT cosine similarity > 0.5`

The positive class consists of each original image paired with each of its 31 retained transformations (31,000 pairs). The negative class consists of every pair of different original images (499,500 pairs).

Existing Datasets5 data are reused: positive CLIP similarities, original CLIP embeddings, original ViT embeddings, and negative ViT similarities. The only missing quantity is the ViT similarity for the positive pairs; `run_exp4.py` calculates it using the local `vit-base-patch16-224` model.

Run from the repository root:

```bash
python3 exp4/run_exp4.py
```

The `results/` directory is generated by the script and contains the positive and negative pair-level results, the calculated positive ViT similarities, and summary metrics.
